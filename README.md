# OU-EKF-for-JR-NMM
Implementation Details of "Splitting-based extended Kalman filtering for parameter inference in the stochastic Jansen--Rit neural mass model". In particular, this contains simulation and inference using OU-EKF, WIE-EKF, and EM-EKF, as well as an implementation of the SMC-ABC algorithm used in the paper.
